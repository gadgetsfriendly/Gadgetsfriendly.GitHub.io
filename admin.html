Quick overview

Products are stored in IndexedDB to avoid the two-item localStorage quota problem. Repair requests and purchase requests are also saved locally with customer name and phone number. Each request has a WhatsApp action for the store and a customer notification action.

Important: browser-local records are not a secure production database. Private serial/IMEI information should only be treated as test data until the backend/receipt stage is connected.
